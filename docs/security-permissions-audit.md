# Audit des autorisations — 19 octobre 2026

Inventaire statique avant modification. Les doublons présents dans les sources sont inclus explicitement.

## Limite du contrat d’autorisation frontend

Vérification du contrat backend du 19 octobre 2026 : le JWT ne contient que `authorities`. Il n’expose ni le scope `PLATFORM`, ni les permissions par établissement, et aucun endpoint « moi » ne fournit ces données au client. Le frontend ne déduit donc jamais ces scopes d’un rôle : les contrôles qui en dépendent restent fermés tant que l’API ne les expose pas. Les routes de permissions génériques, qui ne requièrent que `can_permission_read`, restent accessibles sans scope plateforme. Le backend n’a pas été modifié dans cette mission.

## Plan de modification

1. Corriger les collisions de controllers en conservant les implémentations actuelles des packages controller.
2. Centraliser les permissions fonctionnelles dans les annotations de méthodes ; conserver authentification, licences et contrôles de périmètre.
3. Ajouter une migration Flyway additive : catalogue complet, conversion des attributions génériques existantes et attribution initiale explicite aux administrateurs. Aucun rétablissement au login.
4. Uniformiser les contrôles d’appartenance au compte/établissement et les routes du personnel, des finances annuelles, du portail parent et du dashboard.
5. Aligner les services Angular, guards, menus et actions ; préserver le contexte sélectionné pendant la navigation.
6. Ajouter les tests 403, administrateur sans droit, isolation interétablissements, incohérence année/établissement, catalogue et navigation ; compiler sous Java 21 et Angular 20.
7. Synchroniser README, doc-api et Swagger.

Les permissions existantes can_academic_year_* sont conservées : elles respectent déjà la convention et ne justifient pas des doublons can_school_year_*. Les fiches élèves, employés, matières et postes sont permanents dans leur établissement. Les données annuelles exigent aussi schoolYearId (nom Java historique academicYearId documenté).
